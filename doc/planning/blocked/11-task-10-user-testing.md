## Description
Conduct user testing with real users who don't have all the exact values. Validate that form improvements (instructions, conditional logic, company info) provide good UX and allow completion despite incomplete data.

## Requirements
- Test with users lacking exact data (e.g., tonnage values)
- Test with companies where activities don't apply
- Test with incomplete information
- Measure completion rate
- Measure time to complete
- Identify UX pain points
- Validate data quality of estimates/partial submissions

## Dependencies
- [ ] Task 1: Form instructions (completed)
- [ ] Task 2: Conditional questions (completed)
- [ ] Task 3: Company identification (completed)

## Acceptance Criteria
- [ ] Users can complete form even without exact values
- [ ] Form provides appropriate guidance for each scenario
- [ ] No forced guessing or invalid data
- [ ] Completion rate > 80%
- [ ] Average completion time < 15 minutes
- [ ] Users satisfied with UX (subjective feedback)
- [ ] Data quality acceptable for analysis

## Test Plan
1. Recruit 3-5 test users (diverse companies)
2. Have them complete form without data access
3. Observe where they get stuck
4. Collect timing and feedback
5. Measure:
   - Completion rate
   - Time to complete
   - Frustration points
   - Data accuracy/estimates
6. Document findings and recommendations
